# Agents

One folder = one Hermes agent. Never mix bot tokens, API keys, plugins, or sessions.

| Folder | Agent | Status |
|---|---|---|
| `social-beo` | Beo Social (`social.beo`) | v1 — Telegram, Instagram + Facebook content |
| `leads-beo` | Beo Leads (`leads.beo`) / שי | v1 — Israel outreach, approval in Beo OS |

To add the next agent: new folder, new Telegram bot, new Hermes profile, then a row in `catalog/agents.json`. Never copy `.env`.
