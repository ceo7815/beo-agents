# Lead outreach (שי)

Use this when researching an Israeli business for Beo Leads.

1. Open the site (home + contact). Extract a visible email only. No guessing. No Hunter.
2. If none — `record_lead_candidate` with skip=true. Move on.
3. Score is a sum: ICP 0–40 + site signal 0–25 + pain 0–25 + mailbox quality 0–10. Public email is a gate, never a reason in the copy.
4. Draft Hebrew mail as שי. Subject is always `Beo Systems | הצעת שירותים`. Layout: greeting, blank, כאן שי, blank, one site fact (two lines), blank, spoken pain then spoken offer (no הבעיה/הפתרון labels), then the invite to share business pains and repeating tasks. Services + contact + https://beosystem.com + WhatsApp are auto-appended. Emoji only on השירותים שלנו / דרכי התקשרות. Owner first name only if written on the site. No "רעיון קטן", no page titles. Send is HTML so remaining headers are bold and links are clickable.
5. Skip giants (groups, 50+ staff, “הגדולה בישראל”). Mid-size only. Score below 72 does not go to approval.
6. Save with `record_lead_candidate`. Approval happens in Beo OS, not here.
7. Daily cap: 10 pending_approval. No follow-ups. Human inbox reply → Beo OS lead.
8. After each send/reply/reject, the learning loop updates vertical, product, and copy-style posteriors. Use that playbook on the next draft. Do not invent win rates on tiny samples.
